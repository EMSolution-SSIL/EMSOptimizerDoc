# Dmodel_mixed_builder
An implementation example for editing the Dmodel motor configuration for the `Dmodel_mixed_variabls` project.

## Overview
The permanent magnet material (`NdFeB` / `FerriteMagnet`) is defined from a categorical variable, and the number of coil turns is defined from a discrete variable.  
At the same time, the permanent magnet shape is defined from three-dimensional dimensional parameters.
:::info
To use this implementation example, HoleMagnet Type 51 must be configured in the eMotorSolution project.  
See the eMotorSolution documentation for information about the dimensional parameters.
:::

## Configurable keyword arguments
None
