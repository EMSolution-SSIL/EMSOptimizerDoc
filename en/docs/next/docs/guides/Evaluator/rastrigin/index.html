rastrigin

The Rastrigin single-objective optimization benchmark function[11].

The Rastrigin function is defined as follows. It is known as a multimodal function whose optimal solution is x=0\boldsymbol{x}=\boldsymbol{0}x=0. It is one of the problems considered relatively difficult to optimize with CMA-ES[12].
