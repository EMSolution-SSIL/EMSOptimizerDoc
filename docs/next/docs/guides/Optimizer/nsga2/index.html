nsga2

多目的最適化アルゴリズムNSGA-II[6]のpython実装クラスです。交叉アルゴリズムなどは原著論文[6]に準じています。

概要​

NSGA-IIでは、非優越ソートによって個体にランクを付けます。高ランクの個体を優先して生存させることで集団の進化を促します。また、同ランクの個体間には混雑度（≒目的関数上の類似度）によって優先順位を付けることで、個体の多様性を確保します。

（制約条件を考慮した）NSGA-IIでは、以下の場合に個体iiiがjjjに優越すると定義します。

  • iiiが実行可能解（制約違反無）、jjjが実行不可能解（制約違反有）
  • iiiとjjjの両方が実行不可能解　かつ　iiiの方が制約違反量が少ない
  • iiiとjjjの両方が実行可能解　かつ　iiiが目的関数上jjjに優越する

この優先関係の定義を各個体間に適用し、被優越数が0の個体群をランク1、ランク1の個体群を除いたときに被優越数が0となる個体群をランク2、...とランク付けします。

設定可能なキーワード引数一覧​

  • population_size: int ... 集団サイズ。デフォルト値は（目的数）×100\times 100×100。
  • num_children int ... 1イテレーションあたりに生成する子個体数。デフォルトではpopulation_sizeと同じ値が設定される。
  • bounds: tuple[float, float] | list[tuple[float, float]] ... 各変数の上下限値。
boundsの挙動
  • デフォルト値（設定無の場合） ... [-1, 1]がすべての変数の上下限値に適用。
  • bounds: tuple[float, float]の場合 ... 与えた数値の組がすべての変数の上下限値に設定される。
  • bounds: list[tuple[float, float]]の場合 ... 与えた数値の組のリストが各変数の上下限値に設定される。上下限値の設定は途中までで打ち切ることが可能（この場合、打ち切り以降の上下限値は-1~1に自動設定される）。
  • seed: int ... 乱数シード値。デフォルト値はnull（乱数シード非固定）。
  • mean: np.ndarray | null ... 初期集団の素となるベース解。デフォルト値はnull（ランダム初期化）。
初期集団のSeeding

meanは初期集団のSeeding[19],[20]のための引数です。
これを設定すると，meanを変異させた解集団を初期集団として最適化が実施されます。これは，単目的最適化の解や既存設計周辺のパレート解を重点的に見たいときなどに有用です。

備考

meanの長さlen(mean)が次元数dimに不一致の場合、以下の処理が行われます。

  • len(mean) < dim: 先頭からmeanが格納され、余った箇所は0埋めされる。
  • len(mean) > dim: エラー
  • reference_points: np.ndarray | null ... R-NSGA-IIにおける参照点群。デフォルト値はnull（R-NSGA-II無効化）。
R-NSGA-II

R-NSGA-IIは文献[21]にて提案された多目的最適化アルゴリズムです。個体を淘汰する際，混雑度距離の代わりに参照点との距離を用いることで，参照点に近い解が優先的に生存するように進化が進むという特徴を有します。
理想とする目的関数値が決まっており，その周辺のパレート解を重点的に見たいときなどに有用です。

  • reference_weights: np.ndarray | null ... R-NSGA-IIにおける目的間の重みパラメータ群。デフォルト値はnull（均等重みづけ）。
  • epsilon: float ... R-NSGA-IIにおいて，解の間引き距離を表すεパラメータ。デフォルト値は1e-3。
