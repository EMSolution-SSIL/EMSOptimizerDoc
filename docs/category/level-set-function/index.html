Level Set Function

ここでは、Level Set Functionの実装例 (EMSOptimizer内core/ls_function)を紹介します。

📄️ インターフェース

Level Set Functionのインターフェース定義（LevelSetFunctionInterface）は以下の通りです。

📄️ SimpleLevelSetRadius

半径ごとにレベルを設定するシンプルなLevelSetFunction実装です。

📄️ NGnet

NGnet実装です。NGnet on/off法\[3\]において形状表現に用いられます。

📄️ NGnetMixture

SimpleLevelSetRadiusとNGnetを組み合わせ、ある半径以内の領域についてNGnet関数を適用する実装例。

📄️ NGnetMultiMaterial

3材料最適化用のNGnet実装です。多材料表現型のNGnet on/off法\[3\]において形状表現に用いられます。
