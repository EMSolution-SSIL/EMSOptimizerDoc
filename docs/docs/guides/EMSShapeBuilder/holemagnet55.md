# HoleMagnet55
eMotorSolution HoleMagnet Type 55 永久磁石定義。`IPM8P48S_pto`プロジェクト内で使用されています。

## 概要
10次元の寸法パラメータ$\boldsymbol{d}=\{W0, W1, W2, W3, W4, H0, H1, H2, H3, H4\}$から永久磁石およびフラックスバリア形状を定義します。
:::info
寸法パラメータ情報についてはeMotorSolutionのドキュメントをご覧ください。
:::
