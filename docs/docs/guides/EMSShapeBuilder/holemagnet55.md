# HoleMagnet55
eMotorSolution HoleMagnet Type 55 永久磁石定義。`IPM8P48S_pto`プロジェクト内で使用されています。

## 概要
5次元の寸法パラメータ$\boldsymbol{d}=\{W0, W1, W2, W4, H0\}$から永久磁石およびフラックスバリア形状を定義します。  
なお、HoleMagnet Type 55 は10次元の変数群から定義されるモデルです。寸法パラメータに含めなかった変数群に関してはeMotorSolutionが提案する推奨値に自動設定します。
