# sa_nsga2
多目的最適化アルゴリズムNSGA-II\[6\]にサロゲートモデルによる高速化を導入したpython実装クラスです。

## 概要
電気機器の多目的構造最適化では，多数の形状を解析・評価する必要があるため，計算コストが高くなりやすいという課題があります。1つの対処法として，解析をサロゲートモデル（評価の高速な代理評価モデル）に置き換える手法が広く用いられています。  
本実装例では，NSGA-IIにサロゲートモデルを組み込んでいます。  
サロゲートモデルの実装例は`core/optimizer/surrogate_models`フォルダ内を参照してください。

## 設定可能なキーワード引数一覧
`nsga2`からの追加分のみ記載。  
- `surrogate_model: str` ... 使用するサロゲートモデル名。デフォルト値は`"mlp"`。
:::info
v0.6.3時点では，`mlp`のみ実装済みです。ユーザは`core/optimizer/surrogate_models`内に好きなサロゲートモデルを定義して使用することができます。
:::
- `data_csv_path: str | null` ... サロゲートモデル指定時，サロゲートモデルの学習に用いるcsvファイル。デフォルト値は`null`。
- `enable_adaptive_training: bool` ... 最適化中，サロゲートモデルの更新を行うかどうか。デフォルト値は`True`。
- `surrogate_mode: Literal["full", "full_loop", "assist", "assist_strict"]` ... サロゲートモデルによる高速化モード。デフォルト値は`"assist_strict"`。  
:::tip 高速化モード
- "full" ... 全個体の解析をサロゲートモデルによって代替する。
- "full_loop" ... サロゲートモデル代替による最適化→得られた解集団を真評価→...を繰り返す\[22\]。
- "assist" ... 各世代の内，サロゲートモデルによる評価が優良（高ランク）である個体のみ真評価する\[23\]。
- "assist_strict" ... 各世代の内，サロゲートモデルによる評価が優良（高ランク）である個体のみ真評価する。真評価されなかった個体は強制的に淘汰する\[24\]。
:::
- `eval_init_population_truly: bool` ... 初期集団に限り，サロゲートモデルではなく`evaluator`により真評価するかどうか。デフォルト値は`True`。
