# moead
多目的最適化アルゴリズムMOEA/D\[7\]のpython実装クラスです。

## 概要
MOEA/Dとは、多目的最適化を適切なアプローチによって複数の単目的最適化に分解し、各単目的問題を解く手法です。分解アプローチとして原著論文\[7\]では単純重み付き和（Weighted Sum）、Tchebycheffのアプローチ、Penalty-based Boundary Intersection (PBI) が紹介されています。

本実装では分解後の各単目的最適化問題に1つの個体を割り当て，近傍個体間でSBX交叉を行うことにより集団の進化を促します。最適化過程で得られた解集団は非優越ソート\[6\]され、その結果ランク1となった個体群はパレート解候補としてアーカイブされます。
:::info
単目的最適化へ分解したとき、目的関数間のスケールに大きな違いがあると探索が偏ってしまいます。  
`moead`を使用する際は`coefficient`によって目的関数を正規化することを推奨します。
:::

## 設定可能なキーワード引数一覧
- `num_grid_division: int` ... 多目的最適化のグリッド分解数。デフォルトは`10`。
:::tip[グリッド分解について]
`moead`実装では，多目的最適化問題を単目的のサブ最適化に分解する際，グリッド状（等間隔）に分解を行います。例えば，目的数が2の場合，`num_grid_division + 1`が分解後のサブ問題数となります。  
この値が大きいほどより密なパレート解が得られるようになりますが，計算時間は増加します。
:::
- `neighborhood_size: int` ... サブ問題の近傍数。交叉など，アルゴリズム中の各種処理・判定に利用される。デフォルトは`10`。
- `decomposition_type: str` ... 分解アプローチ。 `weighted_sum`, `tchebycheff`, `pbi`のいずれかに設定します。デフォルト値は"tchebycheff"。
- `bounds: tuple[float, float] | list[tuple[float, float]]` ... CMA-ESの各変数の上下限値。
:::tip[`bounds`の挙動]
- デフォルト値（設定無の場合） ... \[-1, 1\]がすべての変数の上下限値に適用。
- `bounds: tuple[float, float]`の場合 ... 与えた数値の組がすべての変数の上下限値に設定される。
- `bounds: list[tuple[float, float]]`の場合 ... 与えた数値の組のリストが各変数の上下限値に設定される。上下限値の設定は途中までで打ち切ることが可能（この場合、打ち切り以降の上下限値は-1~1に自動設定される）。
:::
- `seed: int | null` ... 乱数シード値。デフォルト値は`null`（乱数シード非固定）。
