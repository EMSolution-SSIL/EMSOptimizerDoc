# AIを活用したコンフィグ設定
EMSOptimizerによって構造最適化を実行するには、メッシュ情報・解析条件・評価予算などに合わせてコンフィグファイルを設定することが重要です。  
手動で設定を行うこともできますが、EMSOptimizerのコンフィグファイルはYAML形式で記述されるため、**生成AIを利用して設定案を作成したり、目的に応じた最適化手法を検討したりすることができます**。  
このページでは、AIをEMSOptimizerの設定作成補助として利用する例を紹介します。  
:::info
AIは誤った・ユーザの意図に沿わない回答をすることがあります。  
AIの回答や生成された設定はユーザ自身が内容を確認してください。
:::

## MCPサーバの設定
EMSOptimizerでは製品固有の知識をAIエージェントに参照させる方法として、ローカルMCPサーバによるリソースの提供を採用しています。  
- ローカルMCPサーバを利用するには、まずSSILから提供されるwhlファイルをpython環境にインストールします。
    - whlをインストールすると、MCPサーバ起動コマンドとして`emsopt-docs-mcp`が環境に登録されます。通常、コマンドの実体はPython環境のScripts（Windows）またはbin（Linux）ディレクトリに置かれます。  
- このコマンドを参照先として各AIエージェントサービスに登録します。
    - 具体的な登録方法はご利用のサービスのドキュメント等を参照してください。  

## 活用例：8P12S永久磁石同期モータの最適化設定の自動生成
代表的な活用方法として、**EMSOptimizerで実施したい最適化内容を自然言語でAIに伝え、コンフィグファイルの下書きを生成する**使い方が挙げられます。  
例えば、「平均トルクを最大化し、トルクリプルを小さくする多目的形状最適化を実行したい」「単目的最適化としてCMA-ESを使いたい」「解析を並列実行したい」といった条件を入力することで、設定項目の候補やYAMLのたたき台を得ることができます。　　

以下の画像は8極12スロットの永久磁石同期モータのメッシュファイルと解析インプットファイルをAIエージェントに渡し、対応するコンフィグファイルを生成した例です。入力から推定できる範囲でAIエージェントが設定を行います。

![AIによるEMSOptimizer設定生成例](/img/ai_usage_config_generation.png)

設定を確認した後、そのまま最適化ジョブの投入まで一貫して実行することもできます。

![AIによるEMSOptimizerジョブ投入例](/img/ai_usage_job_running.png)

他にも、以下のような作業の補助に利用できます。
- `optimization.yaml`のコアオブジェクト設定（`optimizer`、`evaluator`、`level_set_function`など）の下書き作成
- `optimization_problem.yaml`の目的関数、制約条件、解析ケース名の整理
- 並列処理や分散処理、出力設定などの設定項目の洗い出し
- 既存のshowcaseやユーザガイドをもとにした、類似プロジェクト向け設定の調整案作成
- 設定ファイル内の不足項目や値の不整合の確認
:::tip
AIに設定を生成させる場合は、対象プロジェクトの目的、単目的・多目的の別、使用したいEvaluator、解析ケース名、設計変数の数や範囲、必要な制約条件をできるだけ具体的に伝えると、よりユーザの意図に沿った設定が得られます。
:::
